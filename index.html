What Is Blender?

Blender is a free program used for 3D modeling, animation, sculpting, rendering, and other types of digital art. It includes many different tools in one program, which makes it useful for creating complete 3D projects.

More Ways to Create

Sculpting

Sculpting is another way to create models. Instead of editing individual parts of a shape, you can push and pull the model more like digital clay.

Lighting

Lighting can completely change how a 3D scene looks. The position and strength of lights can make a render look brighter, darker, more realistic, or more dramatic.

Ready to Start Creating?

Blender is free to download, so you can start experimenting with your first 3D project whenever you are ready.
